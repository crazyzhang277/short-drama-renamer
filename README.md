# 短剧视频批量更名工具（C++ 桌面版）

一个原生 Windows 小软件，把短剧视频按集数顺序批量改成发布用的标准标题。

> **下载**：[Releases 里的 `short-drama-renamer.exe`](https://github.com/crazyzhang277/short-drama-renamer/releases/latest)
> —— 单文件、免安装、无需运行库，双击即用。

## 一、直接使用

双击下载的程序即可（Release 文件名为 **`short-drama-renamer.exe`**；源码编译版为 **`短剧更名工具.exe`**）。单文件、免安装、无需额外运行库（已静态链接）。
启动时 Windows 会请求管理员权限；确认后即可处理当前账户普通模式无法写入的文件夹。

使用流程只有四步：

1. **选择文件夹** —— 点「浏览...」选视频所在目录，或直接把文件夹拖进窗口
2. **填剧名** —— 例如 `Dignity Reborn`；也可以点「识别剧名」从文件夹名自动认出来
3. **选类型标签** —— 下拉框里挑一个，或在「自定义标签」里自己写
4. **检查预览列表 → 点「执行改名」**

改名是**原地**进行的，不会移动或复制文件。

界面上还有这些便利开关：

- **识别剧名**：从当前文件夹路径里认剧名，盘符（`C:` `D:`）、`Users`、`Desktop`、
  `下载`、`视频`、`短剧`、`新建文件夹` 这类通用目录名会被跳过。认不出来就弹提示，不会乱填。
- **改动即时预览**（默认开启）：改任何设置（换标签、改序号、换排序、改冒号处理……）
  都会自动刷新下方预览列表，不用反复点「预览」。
- **本页教程**：四个功能页各自提供对应说明，点当前页的「本页教程」查看。
- **统计总时长**：在后台按当前选中的文件夹（和「包含子文件夹」开关）统计所有视频时长，
  弹窗给出视频数量、总时长，以及读不到时长的文件清单。详见第六节。
- **剧集统计页签**：顶部切到「剧集统计」，填原剧、海外两个文件夹，后台计算集数、总时长、特殊情况，
  并生成可直接粘贴的报送文案；统计时窗口仍可响应操作。详见第五节。
- **压缩包改名页签**：扫描 ZIP、RAR、7Z、TAR 内的视频文件名；只有识别到单一集数的包才会预览为纯数字文件名，
  如 `5.zip`、`56.rar`。多集、无集数和命名冲突会跳过或拦截；支持撤销。
- **剪映草稿生成页签**：按子文件夹、文件名正则或整个目录分组，预览后生成多时间线草稿；每组一条视频轨，
  片段按预览顺序首尾相接，超过上限时自动拆分草稿。不生成封面图。

## 二、命名规则

```
剧名 - 序号 #short drama #mini drama #micro drama #类型标签.扩展名
```

示例：

```
Dignity Reborn - 01 #short drama #mini drama #micro drama #Billionaire boss.mp4
```

- **剧名**：手填，或点「识别剧名」从文件夹名自动填入。里面的中文标点会自动转成英文标点
  （`，`→`,`、`：`→`:`、`‘’`→`'`、`“”`→`"`、`！`→`!`、`？`→`?`、`（）`→`()`）
- **序号**：从「起始序号」开始递增；「补零位数」控制是否补零（2 = `01`、`02` …，0 = `1`、`2` …）
  集数有断档时，默认会**自动接上**；不想接上就勾「沿用原集数」，详见下面一节
- **固定标签**：`#short drama #mini drama #micro drama` 三个始终带上
- **类型标签**：下拉框选择，只出一个

### 关于冒号

Windows 文件名不允许半角 `:`，所以剧名里如果有冒号，默认换成**全角 `：`**。
下拉框「冒号处理」可以改成 ` - ` 或空格。

同时软件会在 `.rename-tool\titles.txt` 里存一份**带标准英文冒号**的完整标题清单，
复制到发布后台时用那一份即可（点「复制标题清单」按钮）。

### 序号怎么算（集数断档怎么办）

手上有 `1 2 3 8 9 10 11` 这种中间断开的文件时，两种做法都支持：

| 模式 | 界面设置 | 结果 |
| --- | --- | --- |
| **连续编号**（默认） | 不勾「沿用原集数」 | `01 02 03 04 05 06 07` —— 断档被自动接上，原来的 8 变成 4 |
| **沿用原集数** | 勾上「沿用原集数」 | `01 02 03 08 09 10 11` —— 断档保留，8 还是 8 |

细节：

- **连续编号**按排序后的**位置**发号，与文件名里的数字无关。起始序号填 1 就从 01 开始，填 5 就从 05 开始。
- **沿用原集数**用的是从文件名里识别出的集数。识别不出集数的文件（比如 `花絮.mp4`）
  会退回按位置编号，不会被漏掉。
- 沿用原集数时如果两个文件识别出同一个集数（例如 `EP08.mp4` 和 `第8集.mp4`），
  **预览列表里这两行会标红并加上「⚠ 重名」前缀**，状态栏也会提示有几个重名；
  点「执行改名」会被「新名重复」检查拦下，列出冲突清单，不会真的改成重名。
  处理办法：把重复的片子移走，或者勾掉「沿用原集数」改回连续编号。

### 识别剧名是怎么判断的

点「识别剧名」时，软件从文件夹路径**最里层往外**找第一个像剧名的目录名，跳过这些：

- 盘符：`C:` `D:` `E:` …
- 系统/用户目录：`Users`、`Desktop`、`Documents`、`Downloads`、`Videos`、`AppData`、`Program Files` …
- 中文通用目录：`视频`、`短剧`、`影视`、`素材`、`下载`、`桌面`、`新建文件夹`、`待处理` …
- 纯数字、纯符号、没有字母的名字

英文名会自动首字母大写，下划线 / 连字符 / 点会换成空格（`the_lost-HEIRESS.of time` → `The Lost Heiress Of Time`），
`CEO`、`TV` 这类短全大写词保持原样。中文名原样保留。

找不到时不会乱填，会弹提示让你手动输入。

## 三、排序是怎么判断的

「排序方式」下拉框三选一：

| 选项 | 行为 |
| --- | --- |
| **自动识别集数**（默认） | 从文件名里抠集数；能认出 60% 以上就按集数排，否则退回文件名自然排序 |
| **文件名自然排序** | 按文件名里的数字大小排（`EP9` 在 `EP10` 前面） |
| **修改时间** | 按文件修改时间排 |

集数识别的优先级（数字越大越优先）：

| 写法 | 优先级 |
| --- | --- |
| `第12集` | 130 |
| `X集` | 125 |
| `S01E07` | 120 |
| `EP05` / `E05` | 110 |
| `[08]` / `(08)` | 80 |
| 结尾数字 `剧名 13` | 60 |
| 开头数字 `09.mp4` | 50 |

会自动排除这些干扰数字：`240 264 265 360 480 576 720 1080 1280 1440 1920 2160 4320`，
以及 `1900–2099` 的年份。

## 四、安全机制

- **预览先行**：点「执行改名」前必须先预览，看到完整新旧对照表才会动手
- **分阶段改名**：冲突检查通过后，先把待改文件移到同目录临时名，再改成目标名；支持文件名互换
- **冲突拦截**：目标重名、目标已存在、路径超长、非法字符，全部在动手前拦下并列出清单
- **失败回滚**：中途出错会先暂存相关文件再还原原名，避免文件名互换时回滚失败；未能完成时保留进度记录供「撤销上次」继续恢复
- **一键撤销**：每次改名都会在 `.rename-tool` 写入事务记录，点「撤销上次」即可还原，还原后自动删掉该记录

`.rename-tool` 是软件在视频目录里自动建的隐藏工作目录，里面只有撤销记录和标题清单，不碰视频。

## 五、剧集统计（报送文案）

顶部页签切到「剧集统计」，把微信报送要的信息一次算好：

- **原剧文件夹 / 海外文件夹**：各选一个目录（都吃「包含子文件夹」），点「统计信息」两边一起扫
- **智能识别剧名**：选完文件夹会尝试提取目录里的剧名；也可以点对应的「智能识别」按钮重新识别。会跳过“成片 / 全集 / quan”等目录标记，清理类似 `Y-5313-` 的编号前缀，并保留剧名中的括号内容；识别后仍可手动修改
- **集数 / 时长**：自动统计，总时长按各集四舍五入后的秒数相加，显示成 `分:秒`，超过一小时是 `时:分:秒`
- **特殊情况**：按海外剧每集的时长自动判断——哪几集满 1 分钟、其余几集不满 1 分钟、区间多少秒，
  写法和微信模板一致
- **报送文案框**：格式固定（`原剧:` / `集数:` / `时长:` / `海外转译后:` / `特殊情况:`），
  改上面任何一格都会立刻同步；点「复制文案」直接粘给对方

两个文件夹填成同一个也行，只扫一次。集数、时长可以手改，重新统计会覆盖。

## 六、支持的文件类型

```
mp4 mkv mov avi wmv flv m4v ts webm mpg mpeg rmvb rm 3gp m2ts vob ogv divx asf f4v
```

其它文件（`.txt`、`.jpg` 等）会被忽略，不会参与改名。

勾选「包含子文件夹」会递归扫描所有子目录。

### 压缩包集数改名

顶部切到「压缩包改名」，选择目录后点「扫描集数」。软件读取压缩包内视频文件名中的集数，
预览并改成数字文件名，例如 `EP05.mp4` 所在压缩包改为 `5.zip`。扩展名和目录位置保留。

一个压缩包里如果识别到多个不同集数，或没有识别到集数，软件会标记并跳过。目标名称重复或已存在时会阻止整批执行；
改名后可在本页点「撤销上次」恢复。默认只扫描当前目录，勾选「包含子文件夹」会递归扫描。

ZIP 由程序直接读取。RAR、7Z 和 TAR 使用 Windows 提供的 `tar.exe`；如果系统缺少该工具或不支持对应格式，
扫描列表会显示具体失败原因。分卷压缩包会跳过，避免只改其中一个卷导致压缩包损坏。

### 剪映草稿生成

顶部切到「剪映草稿生成」，选择素材目录和一个已存在的输出目录，再选分组方式。参考草稿模板已内置在 EXE 中，无需用户另选。点「预览分组」检查时间线名称及片段顺序，确认后生成。

- **每个子文件夹一条时间线**：按素材目录下的一级子文件夹分组，并递归读取每个子文件夹里的视频；直接放在素材目录根部的视频会单独作为一组，使用素材目录名。
- **按文件名正则分组**：正则需完整匹配不带扩展名的文件名，第 1 个捕获组作为时间线名称；任何视频不匹配时会提示文件名并停止预览。
- **整个目录一条时间线**：递归读取素材目录里的全部视频，时间线名使用素材目录名。

所有组和组内片段都按文件名自然排序。每组生成一条时间线，片段放在同一条视频轨上首尾相接。每个草稿的时间线数量默认为 50，可设置为 1–500；超过上限时自动拆分，输出名为 `素材目录名_Part_01`、`素材目录名_Part_02` 等。同名输出已存在时会停止，不覆盖已有草稿。

「时间线按序号命名」默认关闭，时间线名称保持识别结果。勾选后，时间线名称改为从「起始序号」（默认 1）开始的连续数字 `1`、`2`、`3` …，不再保留原名称。

程序用 Windows Media Foundation 读取视频时长和画面尺寸，不复制视频文件，也不预制封面图；剪映打开草稿后会按其自身行为生成封面。视频必须能被当前 Windows 的 Media Foundation 读取，否则会提示无法读取的文件并停止生成。
每次生成前，程序会把 EXE 内的模板文件写入 `%LOCALAPPDATA%\short-drama-renamer\jianying-template-v1` 供生成器读取；用户无需另选或管理模板目录。

### 统计总时长

点「统计总时长」，弹窗会告诉你这个文件夹一共多少个视频、加起来多长：

![统计总时长](shot-duration-dialog.png)

时长由 Windows 自带的 Media Foundation 读取；容器和编码的可读性取决于系统组件及已安装的解码器。
读不到时长的文件会在弹窗中单独列出，不会计入总时长；`flv`、`rmvb` 等格式在系统缺少解码器时可能无法读取。

## 七、设置记忆

窗口里的路径、剧名、序号、补零、标签等，关掉后会自动存进 `%LOCALAPPDATA%\short-drama-renamer\settings.ini`，下次打开自动带出来。
旧版本保存在程序同目录的 `settings.ini` 会在首次启动时读取并迁移。

## 八、从源码重新编译

需要 MinGW-w64（`g++` + `windres`，GCC 13 以上即可）。没有的话 `install-toolchain.ps1` 会下载便携版到
`%LOCALAPPDATA%\short-drama-renamer\mingw64`，不需要管理员权限；`build.bat` 默认从这个位置找编译器。

```powershell
# 如果换了机器 / 环境丢了，先联网安装工具链（使用清华镜像）
pwsh -NoProfile -File .\install-toolchain.ps1

# 编译
build.bat
```

产物：`短剧更名工具.exe`

源码结构：

```
src/main.cpp        Win32 界面与流程
src/renamer_archives.cpp  ZIP 目录读取与系统 tar.exe 归档读取
src/jianying_draft.cpp   剪映草稿分组、生成与校验
src/jianying_draft.h     剪映草稿模块接口
src/app.rc          资源脚本
src/resource.h     Windows 资源 ID
src/jianying_template/ EXE 内置的清理后剪映模板资源
src/third_party/nlohmann/ JSON for Modern C++ 3.12.0（MIT，许可证随源码提供）
src/app.manifest    Common-Controls v6 + DPI 感知 + 系统版本声明
src/app.ico         图标
```

编译参数：`-std=c++17 -O2 -municode -mwindows -static -static-libgcc -static-libstdc++`
